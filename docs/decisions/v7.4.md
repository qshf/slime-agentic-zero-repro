# V7.4 · 接零风险 infra：learner ABI + 阶段 trace + 版本戳（2026-08-08）

> 分支：`v7`。状态：**代码完成 + 离线全回归绿**（纯 CPU 可验，无需服务器）。
> 定位：`docs/decisions/v7-onward-plan.md` §V7.4「接零风险 infra」+ 折入缺口 1（版本戳）。

## 1. 目标与定位

把 infra（`agentic-rl-infra-lab`）明言「零风险、无新 GPU 行为、尽早接」的两个契约，按「infra as spec」在 repo 内**忠实重写**，用它的 CPU 不变量当验收：
- **learner_contract**：token→causal-target(T-1) 坐标系（`target_mask=loss_mask[1:]`、old_log_probs 同步右移、单一 rollout 版本校验）。
- **learner_metrics**：把 `Trainer` 扁平 metric dict 升级成**分相位 trace**（batch/fwd-bwd/opt/publish 计时 + token/s 分母）。
- **缺口 1（版本戳）**：每条 Sample 戳上 rollout 时的权重版本 → off-policy staleness 有真实来源。

**首要锚点仍是 slime-agentic**：右移 = `torch_actor._pad_batch` 的 `loss_mask[1:]`；版本戳机制对齐源 `types.py:25,165` 的 `Sample.weight_versions`。infra 只提供「落地后语义不变」的可判定不变量。

## 2. 关键设计决策（Plan agent 校验后定）

### 2.1 learner_contract = **校验视图，不是数据变换**（最重要）
训练器（torch_actor/fsdp_trainer）内部**照旧**自己做 `[1:]` 右移消费 loss_mask。`validate_train_data` 只在 opt-in 时把同一批 train_data 过一遍 `LearnerSample` 校验（右移一致 + 单一版本 + causal 对齐），失败即抛。**不改训练器消费的字段** → 对 V0-V7.3 零回归。若改成「变换」（让 train_batch 消费 T-1 的 target_mask），要重写两条 hot path，风险极高——否决。

### 2.2 版本源 = `WeightUpdater.version` int，不是 SGLang meta 串
repo 权威版本源是 `WeightUpdater.version`（单调 int，从 0 起）。主循环调 `generate` 前取 `actor_model.weight_version()` 传入 → 戳到每条 Sample。**不依赖** SGLang `meta_info["weight_version"]`（该字段在本 repo 未验证、且是 `"default"` 串），也不动 solver/GenOutput。偏离源 `Sample.weight_versions: list[str]`：nano 取单 int（更贴 infra int 契约 + repo 权威源），登记在 `sample.py` 字段注释。

### 2.3 custom_convert 拆 turn → 每 turn-row 继承父版本
`custom_convert` 把一条 Sample 拆成 N 个 turn-row。版本列在**每个 turn 循环里**append 父样本版本（+ no-turns 分支），长度 = turn-row 数，与其它列逐行对齐。emit 错成 per-parent 会 desync。

### 2.4 只填可测相位（gap 2 + log_prob 偏离）
- **advantages 传 None**（gap 2 暂缓）：repo GRPO 是逐序列标量 reward，训练器内部广播 [B,1]→[B,L-1]，不物化逐 token advantage。LearnerSample.advantages 字段保留受校验，本版不填（对齐 infra 文档「选项 b」推荐）。
- **log_prob_seconds=0.0**（偏离）：repo 把 log-prob 重算**融进同一次 forward**（log_softmax 紧跟 model(...)），无独立 no-grad log-prob pass。可测的：batch_preparation（列→list+DP-split）、forward_backward（compute 合并）、weight_publish（主循环包 update_weights）。optimizer 未与 fwd/bwd 拆 → 0.0。

### 2.5 退化样本对齐 keep 过滤
`validate_train_data` 先用训练器的 keep 谓词（`len>=2 and sum(mask)>0`，对齐 `_pad_batch`）过滤，否则会对训练器合法跳过的退化样本误报。

## 3. 全部 opt-in / additive（零回归保证）
- `Sample.rollout_policy_version: int|None = None`（默认 None → V0-A3 透明）。
- 新列 `rollout_policy_versions`（只被 opt-in 校验消费）。
- 两个新模块（`learner_contract`/`learner_metrics`）默认不被引用。
- Args 两开关 `learner_contract_validate` / `learner_trace` 默认 False。
- `generate(rollout_id, rollout_policy_version=None)` 新参带缺省 → train.py(V3)/train_async.py(V5)/测试脚本零改。

## 6. 偏离登记（按铁律三要素）

| # | 偏离点 | ①源怎么做 | ②nano 为何偏 | ③等价/何时补 |
|---|--------|----------|-------------|-------------|
| 1 | advantages 逐 token 未物化 | infra/源支持逐 token advantage/GAE | repo GRPO 逐序列标量 reward，训练器内广播；不多搬数据 | 语义等价（标量广播）；逐 token 留将来 GAE/过程奖励（gap 2） |
| 2 | log_prob_seconds=0.0 | 源用独立 no-grad log-prob 前向、单独计时 | repo 把 log-prob 融进训练 forward（一次前向 log_softmax） | 计时不可分（融合）；拆独立 pass 才可测，留后续 |
| 3 | optimizer_seconds=0.0 | 源分别计 fwd/bwd 与 optimizer.step | 本版只在 Trainer 层粗计 compute 合并 | 可后续在 train_batch 内加两个 perf_counter bracket 拆分 |
| 4 | rollout_policy_version 单 int | 源 Sample.weight_versions: list[str]（SGLang meta 累积）| repo 权威版本源是 WeightUpdater.version（单调 int）；更贴 infra int 契约、不依赖未验证 SGLang 字段 | 语义等价（单一 behavior-policy 版本）；多版本 skew 出现时再扩 list |
| 5 | learner_contract 为校验视图非变换 | infra 文档「插在 _convert 后、_pad_batch 前」 | 训练器已内部右移；变换会重写 hot path 且高回归风险 | 语义等价（同一右移被校验）；真要收编右移留大重构 |
