## Context（为什么做 A1）

主线一 V0-V5 把闭环骨架打通，但 rollout 里一直是自造 toy calculator agent。主线二把 toy 换成三个真实
agent。**A1 = MemAgent**：真实 agent 里最简（单引擎、无工具、loss_mask 全 1），最接近主线一 toy，平滑过渡。
教学价值 = **loss_mask 全 1**（没有工具边界），为 A2 AgentFlow 的"executor token=0"（工具边界精华课）做对照。

## 做了什么

**新增（镜像源 agentic/memagent/）**：
- `toy_rl/agent/memagent/rollout.py`：templates（从源搬）+ `_run_memory_loop`（记忆循环唯一实现处）+
  `generate`（real，注入 SGLang chat_fn）+ boxed reward（`_last_boxed_only_string` / `_is_equiv` / `reward_func`）。
- `toy_rl/agent/memagent/data.py`：4 条硬编码 mini QA（`{prompt,label,context}`，context 可切 2-3 chunk、
  答案埋在中后段逼记忆循环）。
- `toy_rl/agent/memagent/stub_rollout.py`：离线 no-SGLang stub，复用**同一个** `_run_memory_loop`、只注入
  造假 chat_fn（记忆轮返回假记忆、最终轮返回 `\boxed{label}`）。
- `scripts/test_a1_memagent.py`：loss_mask 全 1 不变量 + boxed reward + 闭环。

**改动（都朝"更对齐源 + 不破坏主线一"方向）**：

- `mini_slime/rollout_manager.py`：data_source 改为按 `data_source_path` 动态加载、产出 **Sample**（可带
  `metadata["context"]`）；`_next_batch` 深拷贝避免跨轮污染。
- `toy_rl/agent/calculator_data.py`：把原 RolloutManager 里硬编码的 `_PROMPTS` 抽成 calculator 路径的
  data_source loader（返回 Sample），**产出与旧题库完全一致** → 主线一回归零改动。

## 与主线一 calculator 的关键差异（A1 新引入的）

| 维度 | calculator（V1-V5） | MemAgent（A1） |
|---|---|---|
| 引擎/工具 | 单引擎 + calculator 工具 | 单引擎、**无工具** |
| 多轮形态 | 一条增长对话 + 工具返回拼回 | **N 条独立对话**（memory 文本跨轮传递） |
| loss_mask | agent=1 / tool返回=0 | **response 全 1**（无工具段） |
| reward | 精确匹配数字 | `\boxed{}` 抽取 + is_equiv 归一化 |
| 数据 | (prompt,label) 小算术 | (prompt,label,**context** 长文档) |

## 偏离登记（按铁律三要素）

| 偏离点 | ①源怎么做 | ②为何偏离 | ③等价性/何时补齐 |
|---|---|---|---|
| **char 级分 chunk** | 真 tokenizer 按 token 切（MEM_CHUNK_TOKENS） | nano 无真 tokenizer（沿用 V1-V5） | 语义等价（长 context 切段喂记忆循环）；真 tokenizer 分块留 V6 |
| **假 token / 无真 log_probs** | /generate 拿真 token_ids + log_probs | nano 走 chat 端点（V1-V5 已定） | loss_mask 程序化构造等价；真 log_probs 留 V6 |
| **硬编码 mini QA 数据** | prepare_data.py 从 HotpotQA/RULER 生成 JSONL | nano 只需几条能跑通闭环的短文档 | 结构等价（prompt/label/context）；真数据集留后续 |
| **reward 归一化取最简** | 完整 `_strip_string`（10+ LaTeX/分数替换） | 路线图明确 math 归一化只做主流程 | 主流程等价（去空格/换行/小写）；边界 case 不追平 |
| **reward 不做 turn 均摊** | custom_convert 把 reward 均摊各 turn（Multi-Conv RL） | nano fake trainer 不算真梯度，均摊不影响闭环验证 | 记录设计；真训练 credit 分配留主线三 |
| **数据源 loader 返回 Sample 列表** | data_source_cls(args) 从数据集流式取样 | nano 硬编码小集，返回 Sample 列表更直观 | 角色等价（都是 RolloutManager 的数据来源） |
| **记忆循环在 generate 内**（非独立 solver 模块） | 源 memagent 的循环就在 generate 里（无 solver） | **对齐对应源结构**（非偏离）——calculator 抽独立模块是因 agentflow 有 solver | 与源 memagent 结构一致 |

## 实际结果（2026-07-22，本地离线）

`python scripts/test_a1_memagent.py --offline` → **PASSED**：
```
[In which city is the Everbright Tower lo...] chunks=3 turns=4 tokens=2540 trainable=167
  final_output='Based on the memory, the answer is \boxed{Lyonar}.' pred='Lyonar' reward=1.0
single_sample OK
[rollout 0] gen=0.222s train=0.0007s sync=0.0003s | reward_mean=1.000 tokens=5100 weight_v=2
```

- **多轮结构**：3 chunk → 4 turn（3 记忆更新 + 1 最终）。
- **loss_mask 全 1 不变量**：每轮 `loss_mask == [1]*response_length`，无工具边界置 0；trainable=167=各轮 response 之和。
- **boxed reward**：`\boxed{Lyonar}` 抽取命中 label → reward=1.0。
- **闭环**：memagent 数据源+generate+reward 插进 train_ray 跑通，reward_mean=1.0、weight_v→2（=num_rollout+1）。
- **回归**：V0(5/5)/V2(offline)/V3/V4/V5 全绿——data_source 改造对 calculator 路径透明。

## 服务器端到端（2026-07-22，5090 真 SGLang Qwen3.5-4B@30001）

**踩坑 → 修复**：首跑 single_sample **reward=0**——Qwen3.5-4B 是混合推理模型，默认先吐一大段 `<think>`，
把 mem_max_final 预算耗尽、甚至对着记忆模板 meta-rambling（讨论"Updated memory:"是输入还是输出）而不做
任务；memory 轮也被思考噪声污染。结构断言仍过（loss_mask 全 1、多轮），但 agent 没真解题。tokens 高达 11376。

修法（`_sglang_chat_fn`）：`extra_body={"chat_template_kwargs":{"enable_thinking":False}}` 关思考 +
`_strip_think` 剥残留 `<think>` 段（双保险，防污染跨轮记忆）。源 MemAgent 用的是为记忆任务微调的模型无此
问题；nano 接现成模型故显式关思考（同 calculator 对 Qwen3 的适配）。离线 stub 不走此路径、不受影响。

**修复后 PASSED**：
```
[In which city is the Everbright Tower lo...] chunks=2 turns=3 tokens=2629 trainable=481
  final_output='...the Everbright Tower is located in the city of **Lyonar**.\n\n\boxed{Lyonar}' pred='Lyonar' reward=1.0
single_sample OK
[rollout 0] gen=31.913s train=0.010s sync=0.005s | reward_mean=0.500 tokens=5226 weight_v=2
closed_loop OK
```
- 关思考后 tokens 11376→2629、gen 274s→32s；single_sample **reward=1.0**（正确抽出 `\boxed{Lyonar}`）。
- 闭环 reward_mean=0.5：batch 两条 QA 4B 答对一条——**真实模型行为**（小模型 QA 非全对），非 bug，
  loss_mask 全 1 / 多轮 / boxed 机制均已在真 SGLang 上验证。

## 暴露的痛点（引出 A2）
- MemAgent loss_mask 全 1、单引擎单任务：教不了"模型输出 vs 工具返回"的**边界**（README 问题 #2 精华）。
  → **A2 AgentFlow**：Planner→Executor→Verifier 多引擎，executor 生成 token `loss_mask=0`。
