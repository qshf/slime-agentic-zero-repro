## 3. 三条纪律（这版特别容易栽的地方）

1. **fp32 是门，bf16 只是参考**。V8 坑③（漏 qk-layernorm 规约）在 bf16 下 `5e-2` 会被当舍入放过，
   fp32 才把它从 `1.8e-2` 打到 `1.9e-5`（930×）。本版的 §3.3 embedding 漏规约是**同一类错误、同一个指纹**，
   只是最差参数从 `q_norm.weight` 换成 `embed_tokens.weight`。**G2/G3/G4 都必须有 fp32 档。**
2. **度量用全局 rel_L2 + cosine，不用逐参数 max**（V7.5 教训：小信号参数的 bf16 噪声会把 max 虚高到 0.83）。
3. **后端要断言，不要假设**。`NVTE_*` 是**请求**，TE 可能否掉；实选后端在
   `_attention_backends` 缓存里，跑过真前向才有值。
   照抄 [probe_v8.2_cp_packing.py](../../scripts/probe_v8.2_cp_packing.py) 的 C0 写法。
   **同理，「FA2 被调用」也不能靠版本号字符串**——`FlashAttention(2.8.3)` 只证明 TE 看见了包；
   给 `flash_attn_varlen_func` 打计数器才证明 kernel 被调进（V7.6 验 varlen 用的同一招）。

## 4. 明确不做（做了就是跑偏）

- **EP**：Qwen3-0.6B 是 dense，**没有 expert**。不是做不到，是无对象。
- **VPP / interleaved 1F1B**：减 bubble 的调度优化，不改 PP 语义。留 V9 当吞吐旋钮。
- **`DistributedOptimizer`**：维持 V8 偏离 #7（torch AdamW）。它属「省显存」不属「并行语义」。
- **Ray 闭环**：维持 V8 拍板（与 V7.3 高度同构）。本版仍用 `torchrun` 验收。
- **任何吞吐断言**：V8.2 只管对不对。**V9 才问多快**，且必须排在本版之后
  （gloo 走 TCP 经 CPU 中转，现在测吞吐等于在测 TCP 栈）。
