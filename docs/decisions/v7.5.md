# V7.5 · 退休偏离 #1：sequence packing 正确性路径（2026-08-08）

> 分支：`v7`。状态：**代码完成 + 离线全回归绿 + 5090 world=1 等价 PASSED**（fp32 数学精确 + bf16 loss/方向）。
> 定位：`docs/decisions/v7-onward-plan.md` §V7.5「退休偏离 #1（packing 正确性路径）」。

## 1. 目标与定位

`v7.md` 偏离 #1「无 sequence packing」是 V7 唯一未闭合的**正确性**偏离。V7.1 当初暂缓（非放弃），
并**预登记**了 nano 的忠实替代（用块对角 mask 显式隔离）。V7.5 兑现它：给 `FSDPTrainer` 加一条
**opt-in** packing 前向路径，用 infra spike（`04_megatron_te_thd_spike.py`）的验收范式——packed 与
per-sequence 参考的 **loss/grad 逐值等价**——证明隔离精确，从而诚实退休偏离 #1。

**范围**：packing 是 opt-in（`args.train_packing`，默认 False），padding 路径 byte-for-byte 不动、零回归。
本版聚焦**正确性等价**（消除 padding 浪费 + 证明隔离精确），**不**追 varlen 的块级 compute 稀疏
（那要 flash-attn，登记为新偏离 #7）。**需服务器验证**（torch 本地未装）。

## 2. 为什么必须偏离源（三方硬件都缺）

| 路径 | 隔离机制 | 硬件依赖 | 5090 可用？ |
|---|---|---|---|
| 源 slime-agentic | flat + `attention_mask=None` + reset position_ids → **flash-attn varlen 内核**读 cu_seqlens 隐式隔离 | flash-attn | ❌ Blackwell sm_120 无 flash-attn |
| infra spike | flat + cu_seqlens → **TransformerEngine** `attn_mask_type="padding_causal"` | TransformerEngine | ❌ 无 TE |
| **nano V7.5** | flat + reset position_ids + **显式物化 `[1,1,T,T]` 块对角因果 mask** 作 SDPA bias | 仅 eager/sdpa（torch 自带）| ✅ |

照搬源的 `attention_mask=None` 到无 varlen 内核的环境 → 整个 pack 走满因果注意力 → **样本间静默串扰、
loss 算错**（比不做 packing 更危险，故当初暂缓）。infra 文档明言源 varlen 路径"逻辑上等价于 T×T
block-diagonal causal mask"，只是内核不物化它——nano 缺内核，就**显式物化**它。隔离语义等价。

## 3. 关键设计决策

### 3.1 loss 数学抽成共用方法（等价的根本保证）
把 GRPO 单样本 loss（ratio/clip/masked-mean）从 `_microbatch_backward` 抽成 `_grpo_sample_loss(cur_lp,
old_lp, adv, tgt_mask)`，**padding 与 packing 两路共用**。两路唯一差别只在"怎么算出 `cur_lp`"
（padding 每样本一行、packing flat 后按段切）——loss 公式 bit-identical，是 V7.5 等价断言成立的根本，
也让两路更清晰。

### 3.2 显式块对角 mask：dtype / fill / 后端三个约定（源级确认）
`build_block_diagonal_causal_mask(cu_seqlens, T, device, dtype) -> [1,1,T,T]`：
`seg = searchsorted(cu[1:], arange(T), right=True)`；`attend = (seg[:,None]==seg[None,:]) & (j<=i)`；
`where(attend, 0.0, finfo(dtype).min)`。三个约定（读 transformers 5.x 源确认）：
- **HF 直通 4D mask**：`masking_utils.create_causal_mask` → `_preprocess_mask_arguments` 对
  `len(shape)==4` 的 mask **early-exit 原样返回**，不重推因果、不 re-expand 2D → 显式 mask 被完整 honor。
- **加性 bias**：`eager_attention_forward` 做 `attn_weights + attention_mask` → 用加性 float，
  `0.0`=attend / `finfo(dtype).min`=blocked。**不用 `-inf`**：全屏蔽行 softmax 会 NaN；`finfo.min` 安全。
- **仅 eager/sdpa honor 4D mask**（flash/flex 无视 → 静默串扰）→ `_packed_backward` **硬断言**
  `model.config._attn_implementation in ("eager","sdpa")`。宁可炸也不静默算错（本版最危险失败模式）。
- **dtype 匹配激活**：mask dtype = FSDP MixedPrecision `param_dtype`（= `self.compute_dtype`）；
  `position_ids` 必传（RoPE 读它定段内相对位）。

### 3.3 跨边界 target 不泄漏（双重隔离）
per-segment `[start:end)` 取 `logits[start:end-1]` 预测 `tokens[start+1:end]`——边界 token 对**下一段
首 token** 的预测从不形成。与 padding 路径的 `[1:]` 右移、源 `unpack_sequences`+`sum_of_sample_mean`
逐值一致。故隔离有两层：块对角 mask（注意力层）+ shift（target 层）。

### 3.4 fp32 副证靠 `compute_dtype`，不是 `model.float()`
FSDP2 的 `MixedPrecisionPolicy(param_dtype=bf16)` 强制 bf16 前向**无论**存储 dtype——`model.float()`
不产生真 fp32 前向。故给 `apply_fsdp2` 加 `param_dtype` 参数、`FSDPTrainer` 加 `compute_dtype`；
fp32 副证传 `compute_dtype=torch.float32` 真正关掉混合精度，mask dtype 随之 fp32。这样 fp32 才**真的**
是数学精确证明（实测 grad rel_L2 1.7e-4、cosine 0.99999999、loss diff 2.4e-7）——padding 与 packing
逐值一致，隔离无泄漏；bf16 只能到舍入（见 §6 度量分层）。

## 4. nano-minimal 简化（相对源，均无正确性影响）
- **k_partitions=1**：一个 train_batch 打成一个 pack。砍源 `get_seqlen_balanced_partitions` 的多 pack
  均衡（那是多微批吞吐优化）。
- **砍 multimodal / returns / raw_rewards**：nano GRPO 只用 tokens/loss_mask/reward/old_log_probs。
- **old_log_probs 仅全带时才 flat**，否则 None 走 on-policy（对齐源 `use_rollout_logprobs` 语义）。

## 6. 验证

**离线全回归绿**（opt-in 默认 off，fake/torch/padding 路径不破）：V0/V2/V3/V4/V5/V6/A1/A2/A3/V7.4 各 `--offline` PASSED。

**5090 服务器（world=1，GPU2）PASSED**：
```
torchrun --nproc_per_node=1 scripts/test_v7.5_packing.py         # bf16 主门（loss + 方向）
torchrun --nproc_per_node=1 scripts/test_v7.5_packing.py --fp32  # fp32 副证（数学精确）
```
- part (a) 结构全绿：`cu_seqlens=[0,3,5]`（退化 len<2 样本被过滤）、position_ids 每段 reset `[0,1,2,0,1]`、
  块对角 mask（跨段 (3,0)/(0,3)=blocked、同段未来 (0,1)=blocked、同段过去 (2,0)=attend）。
- part (b) 等价——**度量分层**（见下「度量教训」）：
  - **fp32 = 数学精确证明**：`loss diff=2.4e-7`、grad 全局 `rel_L2=1.7e-4`、`cosine=0.99999999`。
    padding 逐行 `[B,L]` 前向与 packing 单条 `[1,T]` 前向**逐值一致** → 隔离无泄漏（本版硬门）。
  - **bf16 主门**：`loss diff=1.7e-4`✅、`cosine=0.9946`✅。magnitude `rel_L2=10.9%` 是 28 层前向两种
    规约顺序的 bf16 epsilon 累积（**非 bug**，fp32 已证精确）→ bf16 只 gate loss + cosine，rel_L2 报 info。

**度量教训（诚实登记）**：初版沿用 infra spike 的绝对 `0.08` bar——但那是 infra spike 里**单层**注意力的
输出/梯度 max_abs bar；搬到 28 层整模型的逐参数 max_abs/max_rel 会被**小信号参数**（如 k_proj，梯度量级小、
bf16 噪声≈信号）放大到虚高（实测逐参数 max_rel 一度到 0.83）。正确度量是**全局 rel_L2 + cosine**（比较两个
梯度**向量**、大信号参数主导），且 **fp32 才是精确证明、bf16 只能到舍入**——按此分层 gate 才诚实。真隔离泄漏
（跨样本注意力）会在 fp32 也留 O(1) 痕迹、不随 dtype 收缩，故 fp32 逐值一致 = 算法正确的充分证据。

## 7. 偏离登记（按铁律三要素）

见 [v7.md](v7.md) 偏离表：#1 退休（~~无 packing~~ → 已补齐，loss/grad 等价）、#6 更新（padding 保留为默认+对照）、
**#7 新增**（隔离=显式 O(T²) 块对角 mask vs varlen O(T) 内核）：

| # | 偏离点 | ①源怎么做 | ②nano 为何偏 | ③等价/何时补 |
|---|--------|----------|-------------|-------------|
| 7 | 隔离机制=显式 O(T²) 块对角 mask，非 varlen O(T) 内核 | flash-attn varlen 读 cu_seqlens 跳过跨块计算（块级稀疏），O(T) | 无 flash-attn；物化整个 T×T mask（HF 4D-mask 走 `create_causal_mask` early-exit 直通）| **loss/grad 等价、吞吐部分等价**：消除 padding 浪费✔、不得 varlen 块级稀疏✘；T≤~3k 无 OOM（bf16 mask 2·T²B，T=3k≈18MB）；装 flash-attn 后换 varlen 得全部吞吐 |

诚实 claim：packing 消除 padding 浪费、证明隔离精确（与 padded 参考 loss/grad 等价）；尚未加 flash-attn varlen 的 compute 稀疏。
